## API Endpoints

### Home Route

```http
GET /
```

Returns Home Page.

### Get All Blogs

```http
GET /blogs
```

Returns all blog posts.

### Add Blog

```http
POST /add-blog
```

Sample Request

```json
{
  "title": "My First Blog",
  "author": "Aliza",
  "content": "Testing Blog API"
}
```

### Update Blog

```http
PUT /update-blog/:id
```

Sample Request

```json
{
  "title": "Updated Blog",
  "author": "Aliza",
  "content": "Updated blog content"
}
```

### Delete Blog

```http
DELETE /delete-blog/:id
```

Example

```http
DELETE /delete-blog/1
```
